# Archived Waypoint body and face studies

Two exploratory clay-style plates showing slimmer builds, human-shaped helmets without the original fin, and faces under raised visors.

- [Pace and Brace](pace-and-brace.png) explores a narrow oval face and a rounded square face.
- [Reach and Skip](reach-and-skip.png) explores a longer face and a heart-shaped face.

These plates are preserved for reference. The human-faced direction was retired and this study was closed before a robotic revision was drawn.
